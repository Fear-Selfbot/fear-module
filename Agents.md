# Инструкции для AI-агентов

## Проект и совместимость

Fear Module — библиотека SDK Python 3.14+ для системы расширений проекта Fear. Публичные символы экспортируются из `fear_module/__init__.py`. Хост-приложение подключает `USER`-обработчики к user-клиенту, `BOT` и `SECRETARY` — к bot-клиенту; сверяйте изменения с `/home/keva1z/Projects/fear`, если репозиторий доступен.

## Изменения

- Считайте `Command`, `ClientType`, `FearModule` и протокол клиента публичным API. Проверяйте типы и примеры использования вместе с хостом.
- Не представляйте заглушки `FearClient.load_modules()`, `unload_modules()` и `schedule_restart()` как реализованную функциональность SDK.
- `register()` вызывается при каждой загрузке/перезагрузке расширения; избегайте необратимых побочных эффектов и дублирования регистрации.
- Поддерживайте `uv.lock` в соответствии с версией `pyproject.toml`; перед изменениями проверяйте `git status`.
- Не включайте секреты и Telegram-сессии в библиотеку или её примеры.

## Проверки

- Синтаксис: `python -m compileall -q src test.py`
- Lock-файл: `uv lock --check`
- `test.py` — устаревший smoke-script, не pytest-набор; на текущем API он завершается ошибкой. Не считать его успешной проверкой. Автоматических тестов, CI и настроенного линтера сейчас нет.
- Для публикации проверьте сборку wheel/sdist и импорт установленного пакета в чистом окружении.
